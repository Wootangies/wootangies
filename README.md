# wootangies
2026년 제6회 K-인공지능 제조데이터 분석 경진대회

주제: ⑤ 자원 최적화 AI — 생산데이터 기반 전력사용량·피크 예측

## 데이터셋

- 파일: `data/raw/okm_augumented_2021.csv` (KAMP 「자원 최적화 AI 데이터셋」)
- 2021년 1~9월, 시간 단위, 257일 × 24시간 = 6,168행 18컬럼
- 컬럼: 날짜, 시간, 15분/30분/45분/60분(시간 내 15분 간격 전력값 4개), 평균(시간당 대표 전력사용량 — 예측 Target 후보), 생산량, 기온/풍속/습도/강수량, 전기요금(계절), day/d/m(요일/일/월), 공장인원, 인건비
- **설비 정보(설비별 가동 여부), 제품 종류 컬럼은 없음** — Peak 저감 시나리오는 설비 단위가 아니라 생산량/시간대 단위로 설계해야 함

## 데이터 품질 이슈 (전처리에서 처리 필요)

1. `시간` 컬럼이 0~23을 벗어나는 행 48개 (2021-07-13, 07-15 부근, 값이 최대 188까지 나타남) — 원인 불명, 처리 방식 합의 필요
2. 결측치: 풍속 3건, 강수량 1건, 공장인원 17건
3. 원본 `day`(요일) 컬럼이 실제 날짜의 요일과 일부 구간에서 불일치 (위 1번 이상값과 연관 추정)

자세한 분석은 `notebooks/01_eda.ipynb` 참고.
